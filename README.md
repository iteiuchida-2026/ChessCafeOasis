## プロジェクト概要 <a id="project-overview"></a>

| 項目 | 内容 |
|------|------|
| **ゲームタイトル** |ChessCafeOasis |
| **ターゲット** |チェスにカジュアルに興味がある人 |
| **制作の目的** |昔から制作したかったチェスのゲームを形にする |
| **一言で説明すると** | チェスができるゲーム空間 |
| **ゲームの目的** | ゲーム内でチェスができる憩いの場を提供する |
| **プレイヤー操作** | マウス左クリックで自分の駒を選択、選択した状態で目的のマスをクリックして駒を移動 |
| **勝利条件** | 相手のキングをチェックメイト（逃げ場のない状態に置く）にする、相手が降参する |
| **失敗条件** | 自分のキングがチェックメイトされる、自分が降参する |
| **引き分け条件** | お互いにチェックメイトにできる駒の組み合わせがない、3回以上同じ盤面となる、ドローの提案を受ける（受けられる） |
| **特徴・工夫点** | |

## 開発ルール <a id="development-rules"></a>

- **Git運用**  
  - 1〜2時間ごとに Commit
  - 1日 2〜3回 Push
  - 作業前に必ず **Pull** して最新を取得
  - Commit メッセージは内容がわかる日本語 or 英語（例：`プレイヤー移動を追加`）

- **Unityプロジェクト設定**  
  - Unity 6（URP）を使用  
  - 各自、同バージョンを統一  
  - 不要アセットは追加しない（軽量管理）
  -   - `.gitignore` は Unity 公式テンプレートを使用

- **フォルダ構成推奨**
```
Assets/
└─ game/
    ├─ Scripts/
    |    
    |    
    |    
    |    
    |    
    ├─ Prefabs/
    |    └
    ├─ Scenes/
    |   ├
    |   └
    ├─ Fonts/
    ├─ Images/
    ├─ Materials/
    ├─ ScriptableObjects/
    ├─ Shaders/
    └─ Audio/
        ├─ BGM/
        └─ Sounds/
```
