## Git運用方針 <a id="git-Operation"></a>

| ブランチ名| 用途・役割 | マージ先|
|------|------|------|
| **master** | リリース用ブランチ。ここで作業はしない。 | -|
| **develop** | masterブランチへのマージするためのクッションブランチ。1日の作業終わりに作業内容をPullRequestで保存する。 | master|
| **feature**| 開発用のブランチ、作業の区切りでdevelopにマージ後に削除して新たな作業に入る。| develop|
| **fix**| バグ修正用のブランチ、作業が終わればdevelopへマージ後に削除する。| develop|


- **コミットメッセージ**  
  - feat: 新しい機能
  - fix: バグの修正
  - docs: ドキュメントのみの変更
  - style: 空白、フォーマット、セミコロン追加など
  - refactor: 仕様に影響がないコード改善(リファクタ)
  - perf: パフォーマンス向上関連
  - test: テスト関連
  - chore: ビルド、補助ツール、ライブラリ関連

## 開発ルール <a id="development-rules"></a>

- **Git運用**  
  - 1〜2時間ごとに Commit
  - 1日 2〜3回 Push
  - 作業前に必ず **Pull** して最新を取得
  - Commit メッセージは内容がわかる日本語 or 英語（例：`プレイヤー移動を追加`）

- **Unityプロジェクト設定**  
  - Unity 6（URP）を使用  
  - 各自、同バージョンを統一  
  - 不要アセットは追加しない（軽量管理）
  -   - `.gitignore` は Unity 公式テンプレートを使用

- **フォルダ構成推奨**
```
Assets/
└─ game/
    ├─ Scripts/
    |    
    |    
    |    
    |    
    |    
    ├─ Prefabs/
    |    └
    ├─ Scenes/

    ├─ Fonts/
    ├─ Images/
    ├─ Materials/
    ├─ ScriptableObjects/

    └─ Audio/
        ├─ BGM/
        └─ Sounds/
```
